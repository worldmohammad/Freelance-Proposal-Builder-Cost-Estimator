# 📄 Freelance Proposal Builder & Cost Estimator

**100% Client-Side. Zero Server. Absolute Privacy.**

A professional offline tool for freelancers and consultants to create stunning project proposals with automatic cost estimation. Build WBS, calculate totals with buffer and tax, and generate print-ready A4 documents—all in your browser.

## ✨ Features

- **📊 WBS Builder:** Add tasks/phases with hours and auto-calculated costs
- **💰 Smart Calculator:** Hourly rate × hours + expenses + buffer% + tax%
- **📝 Rich Content:** Introduction, deliverables, SLA terms
- **🖨️ Print-Ready:** Professional A4 proposal layout
- **💾 Local Storage:** All proposals saved in IndexedDB
- **📥 Backup/Restore:** JSON export/import (Pro)
- **🔒 100% Offline:** No server, no tracking
